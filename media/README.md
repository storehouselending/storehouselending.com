# Home page media

Upload these here (on GitHub: **Add file → Upload files**), using these exact names:

| File | What it is | Tips |
|---|---|---|
| `hero.mp4` | Looping background video for the home page | MP4 (H.264), landscape, 1920×1080 or 1280×720, 10–30 seconds, ideally under 10 MB. It plays muted. |
| `hero-poster.jpg` | A still frame from the video | Shows instantly while the video loads, and on phones in low-power mode. |
| `bgm.mp3` | Background music for the home page | A visitor taps "Play music" to start it (browsers block sound until someone taps). 1–3 minutes, loops. |

Without these files the home page simply keeps its original dark-blue look.
Only use video and music you have the rights to (for example Pexels, Pixabay, or your own).
