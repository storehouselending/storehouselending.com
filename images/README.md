# Images

Upload site photos and logos to this folder (on GitHub: **Add file → Upload files**).
Use these exact file names and they show up on the site automatically:

| File name | Where it shows |
|---|---|
| `logo.jpg` (or `logo.png`) | Home page, above the location badge |
| `hero.jpg` | Home page background behind the headline |
| `loan-conventional.jpg` | Home page, Conventional tile |
| `loan-government.jpg` | Home page, Government tile |
| `loan-nonqm.jpg` | Home page, Non-QM tile |
| `loan-jumbo.jpg` | Home page, Jumbo tile |
| `loan-reverse.jpg` | Home page, Reverse tile |
| `partner-petersburg.jpg`, `partner-lienbridge.jpg`, `realtypeoples.jpg` | Footer partner logos (add more in `js/site.js` under `partners`) |

File names are case-sensitive: `logo.jpg` works, `Logo.JPG` does not.
